# Gallery Images

## Required Images for Mobilfunk Section

### mobile-network.jpg
- **Purpose**: Display in the Mobilfunk section 3D tablet scroll
- **Recommended Size**: 1920x1080px or higher
- **Format**: JPG
- **Description**: Image showing mobile network infrastructure or telecommunications technology

## Adding Images

To add images to this folder:
1. Upload your image file to `public/fotos/gallery/`
2. Ensure the filename matches the reference in the component
3. The image will be automatically displayed in the Mobilfunk section
